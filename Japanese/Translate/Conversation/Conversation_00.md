## 2. 翻訳

### 原文

```
    Ａ（田中）： 先輩（せんぱい）

    Ｂ（鈴木）： 后輩（こうはい）

    場面（ばめん）： 仕事（しごと）のあと、居酒屋（いざかや）で。

    Ａ： お疲（つか）れ！まずは生（なま）ビール２つでいい？

    Ｂ： はい、大丈夫（だいじょうぶ）です！あ、私（わたし）はハイボールにしようかな。

    Ａ： OK。じゃあ、生（なま）１つとハイボール１つで！あと、スピードメニューから枝豆（えだまめ）と塩（しお）キャベツも頼（たの）んでおこう。

    Ｂ： いいですね！そういえば、今日（きょう）のプレゼン、すごく上手（じょうず）くいきましたね。お疲（つか）れ様（さま）でした！

    Ａ： ありがとう！Ｂさんのおかげで助（たす）かったよ。資料（しりょう）の準備（じゅんび）、丁寧（ていねい）にやってくれて助（たす）かった。

    Ｂ： そう言（い）っていただけると嬉しい（うれしい）です。じゃあ、今日（きょう）はパッと飲（の）んで、早（はや）めに帰（かえ）りましょう！

```

### 訳文

```
    Ａ（田中）： 前辈

    Ｂ（鈴木）： 后辈

    情景： 工作之后，居酒屋内。

    Ａ： 辛苦了！首先来两杯生啤酒怎么样？

    Ｂ： 好的、没问题！那、我还是改选嗨棒吧。

    Ａ： OK。那、请来一杯生啤，一杯嗨棒！另外、拜托从快速菜单里点一个毛豆和盐昆布包菜吧。

    Ｂ： 好的！话说回来、今天的汇报、非常顺利的结束了呢。辛苦您了！

    Ａ： 感谢！多亏了B先生你的帮助啊。准备资料很细致，真的省了我不少力。

    Ｂ： 能听到您这么说我太高兴了。那、今天就好好喝一下，早点回家吧！

```

### 語彙

| 単語 / フレーズ | 意味 | コロケーション | 例文 | メモ |

```
  1.生（なま）：名词，在居酒屋专指“生啤酒”（生ビール）。
  2.ハイボール：外来语（Highball），高球酒（威士忌加碳酸水/苏打水调制成的饮品）。
  3.スピードメニュー：外来语（Speed Menu），居酒屋的“快手菜/冷盘”（上菜极快的小菜）。
  4.枝豆（えだまめ）：名词，毛豆。
  5.プレゼン：外来语（Presentation 的缩写），演示汇报、产品/方案介绍。
  6.上手（うま）くいく / うまくいく：动词，顺利进行、成功。（注意词变形：うまくいきました）。
  7.パッと：副词（片假名写出），表示动作干脆利落、痛痛快快、一下子。
```
