## 2. 翻訳

### 原文

```
    面接官：どうぞ、お入りください。

    田中：失礼（しつれい）いたします。田中（たなか）と申します。本日はよろしくお願いいたします。

    面接官：どうぞ、お座（すわ）りください。

    田中：失礼いたします。

    面接官：それでは、まず簡単に自己紹介（じこしょうかい）をお願いします。

    田中：はい。田中と申します。大学では経営学（けいえいがく）を専攻（せんこう）しておりました。学生時代は飲食店でのアルバイトに力を入れ、
      コミュニケーション能力やチームワークを学びました。本日は緊張（きんちょう）しておりますが、精一杯（せいいっぱい）がんばりますので、よろしくお願いいたします。

    面接官：ありがとうございます。では、弊社（へいしゃ）を志望（しぼう）した理由を教えていただけますか。

    田中：はい。貴社（きしゃ）の「お客様第一」という理念（りねん）に強く共感（きょうかん）したからです。グローバルに事業を展開（てんかい）している貴社で、
      私の語学力（ごがくりょく）とアルバイトで培（つちか）った接客スキルを活かしたいと考え、応募いたしました。

    面接官：なるほど。ご自身の長所（ちょうしょ）と短所（たんしょ）は何だと思いますか。

    田中：私の長所は、最後まで諦（あきら）めずにやり遂（と）げる「粘り強（ねばりづよ）さ」です。一方、短所は心配性（しんぱいしょう）なところです。
      そのため、普段から事前（じぜん）の準備や確認をしっかり行うよう心がけています。

    面接官：分かりました。最後に、何か質問（しつもん）はありますか。

    田中：はい、一つ質問がございます。入社（にゅうしゃ）までに準備しておくべきことや、勉強しておいたほうがいいことはありますでしょうか。

    面接官：そうですね、特に〇〇の知識（ちしき）を身につけておくと良いと思いますよ。

    田中：かしこまりました。ご回答（かいとう）ありがとうございます。入社までにしっかり準備しておきます。

    面接官：本日は以上となります。ありがとうございました。後日（ごじつ）結果をご連絡いたします。

    田中：本日はお時間をいただき、誠（まこと）にありがとうございました。失礼いたします。

```

### 訳文

```
    面试官：请进。

    田中：打扰了。我是田中，今天请多多关照。
    
    面试官：请坐。

    田中：好的，谢谢。

    面试官：那么，首先麻烦请你简单的自我介绍一下。

    田中：好的。我叫做田中。在大学，学习经营学。学生时代我把精力投入到了餐饮店的兼职中，锻炼了沟通能力和团队协作能力。
      今天有一些紧张，但是我会加倍努力，请多多关照。

    面试官：感谢，那么请告诉我希望加入我们公司的理由。

    田中：好的。因为贵社的顾客第一的理念我非常认同。因为贵公司在全球开展事业，我希望发挥我的语言能力以及在兼职中积累的服务技巧，所以参加了应聘。

    面试官：原来是这样。你认为你自己的长处与短处是什么呢。

    田中：我的长处是不到最后不会放弃尝试这种顽强的毅力。另一方面，我的短处是多虑的性格。正因如此，从平时开始，我一直时刻注意做足事前准备和仔细核对。

    面试官：我知道了。最后，你有什么想要提问的吗。

    田中：是的，有一个疑问。入职之前，应该准备的事情和学习的方面有什么呢。

    面试官：这样啊，在特定方面的〇〇知识有所掌握会比较好，我是这么认为的。

    田中：我明白了。感谢您的回答。加入公司之前会好好提前准备。

    面试官：那今天就先这样。感谢。之后的结果会和你进行联络。

    田中：今天为我花时间面试，真诚的感谢。失礼了。

```

```
    田中：はい。一番の理由が「お客様第一」という貴社の理念だからです。グローバルで事業を展開しますので、私の語学力とアルバイトで学んだスキルを活かすと考え、応募いたしました。

    面接官：なるほど。ご自分の長所と短所はどうですか。

    田中：私の長所は最後までに諦めないような態度。一方、私の短所は考えることが多いです。そのため、普段から、私は事前準備と確認をしっかりしておきま。

    面接官：わかりました。最後に何か質問がありますか。

    田中：はい、一つ質問です。入社までに何を準備しておけばいいですか。

    面接官：そですね、特に〇〇方面の知識を身につけるほうがいいと思います。

    田中：かしこまりました。ありがどうございます。貴社に入社までにしっかり準備します。

    面接官：じゃ、今日は終わります。ありがどうございます。後で結果をご連絡いたします。

    田中：今日はお時間をいただき、本当にありがどうございます。失礼します。

```

### 文型

文型
```
  1.〜よう心がける：动词辞书形 / 否定形 + よう心がける，时刻注意/努力做到
  2.〜だからです：最主要的原因是因为
  3.〜を活（い）かす：名词 + を活かす，发挥/活用
  4.〜ていただく：我让对方为我做了某事，我对此心存感谢
  5.〜ておけばいい：提前做准备什么比较好
```
