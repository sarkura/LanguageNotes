## 2. 翻訳

### 原文

```
    面接官：「本日はお忙しい中、弊社の面接にお越しいただきありがとうございます。それではまず、簡単な自己紹介とこれまでのご経歴を1〜2分程度でお願いいいたします。」

    回答例：「こんにちは。**陳定浩（ちん ていこう）**と申します。本日はお時間をいただき、ありがとうございます。
    私は Unreal Engine の開発エンジニアとして、これまで C++ や PCG 機能を活用した開発に従事してまいりました。主にグラフィックやアセット関連の Pipeline 構築を中心にしております。本日はどうぞよろしくお願いいたします。」

    面接官：「これまでのプロジェクトの中で、一番達成感のあった実績や、困難を乗り越えた経験について教えていただけますか？」

    回答例：「私がこれまで関わったプロジェクトの中で、一番達成感があった実績は主に2つあります。1点目は、Auto PCG Pipeline の開発です。具体的には、Landscape の自動生成技術や Scatter Point の制御ロジックの実装です。また、Memory を節約するために、Bit 操作を活用して Texture Compression を行う仕組みも構築しました。2点目は、Dynamic Atlas の実装です。これは、Runtime での Draw Call を削減し、描画パフォーマンスを Optimization（最適化） するために開発いたしました。」

    面接官：「Dynamic Atlas を実装する際に一番苦労した点と、それをどのように解決されたかについて、もう少し詳しく教えていただけますか？」

    回答例：「一番苦労した点は、Texture の Life Cycle（生存期間）の管理です。具体的には、Hash Table を構築し、Texture Data を Atlas に Copy すると同時に、Texture の Full Path（全パス）を Key として Hash Table に保存する仕組みを作りました。Rendering の際は、**Texture Name（または Path）で Search（検索）**し、Atlas 内の該当エリアを参照して描画する処理を行っています。」

    面接官：「今回、転職を考えられた理由と、なぜ数ある IT・ゲーム会社の中で**弊社に応募されたのか（志望動機）**について教えていただけますか？」

    回答例：「転職の理由は、日本の高品質なゲーム開発に、自身の技術で挑戦したいと考えたからです。私自身、これまで多くの日本のアクションゲームをプレイしてきました。特に**『SEKIRO: SHADOWS DIE TWICE』**をプレイした際、その圧倒的なグラフィック表現と世界観に強く感銘を受けました。これまで培ってきた Unreal Engine、C++、そして Pipeline / Rendering 最適化の技術を生かし、貴社のような高いクオリティを追求するチームで世界中のユーザーを魅了するゲームを作りたいと考え、今回応募いたしました。」

    面接官：「最後に、陳さんから弊社に対して何か質問や確認したいこと（逆質問）はございますか？」

    回答例：「ご回答ありがとうございます。1点お伺いしたいのですが、こちらの Team では、今後どのような Genre（ジャンル）や Type（タイプ）の Game を創作・開発していきたいとお考えでしょうか？ 差し支えなければ、お聞かせいただけますでしょうか？」
```

### 逆翻訳（話し言葉の日本語）

```
    面接官：はじめまして、山田と申します。今日はお忙しいですが、面接に参加して、ありがとうございます。簡単な自己紹介と今までの経歴を一、二分ぐらい程度でお願いします。

    回答：はじめまして、陳定浩と申します。本日はお時間をいただき、ありがとうございます。私は五年前からUnrealのProgrammerとしてゲームを作っています。私の得意な分野は2つです。１点目はPCGのPipelineのDesignです。Landscapeの自動的な生成の方法や植物のScatterの方法など、いろいろなPCGの技術を活用した経験があります。２点目はUnrealのToolChainを開発し、ProgramのBUGをFixし、性能をOptimizationします。UnrealEngineの構造を知っているおかげで色々な問題や性能を上げることができます。

    面接官：これまでのProjectの中で、一番達成感のことはどうですか。そして、困難を乗り越えた経験について教えてもらえますか。

    回答：一番達成感のことは2つです。まずはAuto PCG Pipelineの実装です。この中で3点目が一番重要なことです。1点目は自動的なLandscapeの生成です。GISのDataを使いて現実的な地形のような地形を、ゲーム中にできます。２点目はScatterの自動的な生成です。３点目はMemoryを節約するために、Bitの操作を活用します。そして、Dynamic Atlas の実装です。これは、Runtime での Draw Call を削減し、PerformanceをOptimizationするために開発いたしました。

    回答：ご回答ありがとうございます。1点お伺いしたいのですが、こちらのTeamでは、今後どのようなTypeのGameを開発していきたいか、教えていただけますか。
```

## 3. 復習

### 文型

| 文型 | 例文 | メモ |

文型
```
  1.〜として：名词 + として，作为…
  2.五年前から〜ている：起点用から，和ている搭配表示从那时持续到现在
  3.〜おかげで：普通形 / ている + おかげで，多亏…才能…
  4.〜ために：辞书形 / 名词 + のために，为了…
  5.〜際（さい）に：辞书形 / 名词 + の際に，在…的时候
  6.AをBとして：把A当作B
  7.〜に参加する：参加的对象用に，不用を
  8.〜ていただけますか：可能形，请对方为自己做某事
  9.〜たいのですが：想做某事，用来委婉提起下文
  10.〜のような：名词 + のような，像…那样的
```
例文
```
  1.私は五年前からUnrealのProgrammerとしてゲームを作っています。
  2.UnrealEngineの構造を知っているおかげで、性能を上げることができます。
  3.Memoryを節約するために、Bitの操作を活用します。
  4.Dynamic Atlasを実装する際に、一番苦労した点はLifeCycleの管理です。
  5.TextureFullPathをKeyとして保存します。
  6.面接に参加して、ありがとうございます。
  7.貴社のようなTeamに参加して、世界中で有名なゲームをつくりたいです。
  8.貴社の応募に参加しました。
  9.困難を乗り越えた経験について教えてもらえますか。
  10.1点お伺いしたいのですが、今後どのようなTypeのGameを開発していきたいか、教えていただけますか。
```
メモ
```
  参加する / 応募：对象用に（面接に参加、Teamに参加、応募に参加）。を参加是错的。
  五年前に + ている：に是时间点，和持续态冲突。从那时一直做到现在，用五年前から。
  得意な分野：得意是な形容词，连体用な，不用の。
  色々な：连体用な，不用の。
  できる：可能动词，ます形是できます，不是できります。
  あげる：他动词，宾语用を（性能を上げる）。が上げる是错的。
  教えてもらえますか / いただけますか：请求对方时用可能形。もらいますか听起来像「你要我告诉你吗」。
  その中で：表示「其中」。その中に是「在里面」。
  世界中で有名：在某个范围内有名用で。
  引用后接提问：〜していきたいか、教えていただけますか。不要写成〜していきたいと教えていただきますか。
```
