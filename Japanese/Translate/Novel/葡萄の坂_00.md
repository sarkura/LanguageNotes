## 2. 翻訳

### 原文

```
    記憶にあるはずがないのに、懐かしい風景というのはある。
  　一つ角を曲がった先の小道は、葡萄畑の間をうねうねと下っていた。
  　丁寧に積まれた石垣と石段で縁どられた畑の葡萄は葉を大きく広げていて、明るい陽射しが緑に透けている。若い葡萄の房は豊穣の壁画のモチーフそのままに垂れていて、一部はほんのり色づいていた。
  　私は石垣の間の坂道をのんびりと下って行った。
  　つづら折りの青と緑の風景に、名前を知らない赤い花が朱をさした。家だ。その白っぽい明るいクリーム色の壁にオレンジの屋根の小さな家の庭は、急な石段の脇を石垣で段々に囲って作られており、オリーブやレモンの木の間に、ハーブと花の鉢が並んでいた。
  　「あっ」
  　一抱えもある大きな壷を抱えた女性が、庭の石段の端でバランスを崩したのを見た私は、咄嗟に駆け寄って手を貸した。
  　「ありがとうございます」
  　その品の良い婦人は壷を降ろすと、狼狽を面に表すまいと努めつつ、鼓動が早くなっているのであろう胸を控えめに抑えながら礼を言った。
  　お礼に……と、私はその婦人の家のテラスでワインを頂くことになった。
```

### 訳文

```
  明明不可能在记忆中，令人怀念的风景确实存在。
  拐过一个转角之后的小路在葡萄地里弯弯曲曲延伸下去。
  农田被整齐砌筑的石墙和石阶环绕着，其中的葡萄叶舒展开来，明媚的阳光穿透片片绿意。青涩的葡萄串像壁画中的葡萄图案一模一样地垂挂着，淡淡的染上颜色。
  我在夹在石墙间的坡道上悠闲地向下走去。
  漫山蓝绿盘旋的风景里，几朵不知名的红花点缀着朱红。家啊。那个满白色明亮的奶油色般的墙壁上，橘色的屋顶的小家的庭院，在陡峭的石阶旁被陡峭的石墙包围着，橄榄树和柠檬树中，香草和花盆整齐的排列着。
  啊。
  见一位抱着硕大陶罐的女子在庭院石梯拐角处脚下一滑，我赶忙跑过去帮忙。
  谢谢你。
  那位举止端庄的夫人一放下壶，一边努力克制露出狼狈的表情，轻轻按抚着想必是因心跳加速而起伏的胸口向我道谢。
  为了表示感谢，我应邀在这位妇人家的露台上喝了杯葡萄酒。
```

### 逆翻訳（話し言葉の日本語）

```
  記憶にはないはずなのに、懐かしい風景はある。
  一つ角を曲った先の小道は、葡萄畑の間をうねうねと下っていた。
  石垣と石段で丁寧に囲まれた畑で葡萄の葉は大きく広がっていて、明るい陽光が緑に透けている。若い葡萄の房は豊穣の壁画のモチーフのように垂れていて、あわく色づいていた。

```
